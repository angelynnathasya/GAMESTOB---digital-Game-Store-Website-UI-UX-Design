# GAMESTOB --- Digital Game Store Website

A gaming e-commerce website concept featuring a game catalog, product
filters and sorting, shopping cart, checkout form, company information,
and store locations. Designed with a dark gaming aesthetic and a
user-friendly browsing experience.

## Overview

GAMESTOB is a gaming marketplace website concept designed to help users
discover and explore games, review product details, and move through a
structured purchase flow. 

The project includes five main pages:
- **Home** --- Highlights featured
games, latest releases, best sellers, and new downloadable content
(DLC).
- **Catalog** --- Presents the game collection with search,
genre/platform/price/rating filters, and sorting options.
- **Purchase** --- Displays billing and payment form fields alongside an order
summary.
- **About Us** --- Introduces GAMESTOB, its story, and its core
values.
- **Locations** --- Presents information about the concept's
physical store locations.

## Key Features

### Home

-   Featured game banner and preorder call-to-action
-   Latest releases and best-selling games
-   New DLC section
-   Search, shopping cart, and user profile entry points
-   Footer with support links and newsletter subscription

### Catalog

-   Game product cards with cover image, title, genre, platform, and
    price
-   Search by game name
-   Filters for genre, platform, price range, rating, sales, pre-orders,
    DLC, and bundles
-   Sorting by popularity, newest, price, and rating
-   Apply and reset filter controls

### Purchase

-   Billing details form
-   Payment information fields
-   Order summary with subtotal, tax, and total
-   Confirm Payment button
-   JavaScript validation requirements for form inputs

### About Us

-   Brand introduction and story
-   Core values: Trust & Safety, Passion for Gaming, Customer First,
    Quality & Authenticity, and Growth & Innovation

### Locations

-   Store cards for Jakarta, Singapore, Tokyo, and Sydney
-   Store imagery, address, country, and operating hours

## UI/UX Principles

The documentation describes the following Human-Computer Interaction
(HCI) principles: 
- **Visibility:** Payment information and order
summary are presented clearly.
- **Consistency:** Colors, typography,
icons, and layout are consistent across pages.
- **Feedback:** Form
validation communicates input errors.
- **Error Prevention:** Users can
review the order summary before confirming payment.
- **Efficiency:**
Checkout information is organized on one page.
- **Learnability:** The layout follows familiar e-commerce patterns.
